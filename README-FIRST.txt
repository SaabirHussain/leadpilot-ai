LeadPilot AI — AI Lead Follow-Up Kit

Inside: the local app, prebuilt browser interface, Docker files, launch scripts,
fictional demo data, CSV template, setup/privacy/troubleshooting guides and license.

1. Extract this entire ZIP to a folder you own (not inside the ZIP viewer).
2. Read docs/QUICK_START.md. Choose Docker Compose, or install Python 3.10+.
3. Docker: docker compose up --build -d. Without Docker: run scripts/start.sh
   (macOS/Linux) or start.bat (Windows; provided, not tested on Windows).
4. Open http://127.0.0.1:8000, create your owner account and complete onboarding.
5. Try the fictional demo, review a draft, then copy it or open your email app.

No Node.js is needed for the prebuilt non-Docker installation. Internet is required
for initial dependencies/images; ongoing external AI calls require internet too.
LeadPilot never sends email automatically. Provider usage may cost money.
Back up your workspace before upgrades. Read LICENSE (draft pending legal review).
